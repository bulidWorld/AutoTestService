# 日志规范

> 本规范从《单体应用开发规范》（Agetns.md）中拆出，涵盖日志框架、存放位置、日志内容、敏感信息与日志轮转。

## 1. 统一的日志记录规范

所有单体应用必须使用统一的日志框架。

禁止：

```python
print("user login")
```

生产环境应该使用：

```python
logger.info("user login")
```

日志级别统一为：

```text
DEBUG
INFO
WARNING
ERROR
CRITICAL
```

一般生产环境：

```text
INFO
```

开发环境可以：

```text
DEBUG
```

## 2. 日志存放位置规范

所有应用日志统一存放：

```text
/var/service/log/{服务名称}/
```

例如：

```text
/var/service/log/my-service/
```

目录：

```text
/var/service/log/my-service/
├── application.log
├── error.log
└── access.log
```

如果应用比较简单，也可以只使用：

```text
/var/service/log/my-service/application.log
```

## 3. 日志内容规范

日志至少应该包含：

```text
时间
日志级别
服务名称
线程/进程
模块
请求ID
日志内容
异常信息
```

例如：

```text
2026-09-06 19:20:31.123 INFO
my-service
request_id=abc123
UserService
user login success
user_id=10001
```

推荐 JSON 日志：

```json
{
  "timestamp": "2026-09-06T19:20:31.123+08:00",
  "level": "INFO",
  "service": "my-service",
  "request_id": "abc123",
  "module": "UserService",
  "message": "user login success",
  "user_id": 10001
}
```

这样后续接入：

```text
ELK
Loki
Prometheus
Grafana
```

会比较方便。

## 4. 日志中的敏感信息规范

日志中严禁记录：

```text
密码
数据库密码
Access Token
Refresh Token
JWT
API Key
银行卡号
身份证号码
完整手机号
```

例如禁止：

```python
logger.info(
    "login username=%s password=%s",
    username,
    password
)
```

应该：

```python
logger.info(
    "login success username=%s",
    username
)
```

## 5. 日志轮转

不能让：

```text
/var/service/log/my-service/application.log
```

无限增长。

必须配置日志轮转。

例如：

```text
application.log
application.log.1
application.log.2
application.log.3
```

或者按日期：

```text
application-2026-09-04.log
application-2026-09-05.log
application-2026-09-06.log
```

推荐使用 Linux 的：

```text
logrotate
```

统一控制日志大小和保存周期。

例如：

```text
最大 100 MB
保留 30 天
压缩历史日志
```
