AI 开发指导规范：基于 YAML 契约驱动的 FastAPI 动态注册架构


📌 核心原则

1. 设计优先 (Design-First)：严禁直接编写 Python 路由代码。必须先编写符合 OpenAPI 3.0+ 规范的 YAML 文件。
2. 单一数据源 (Single Source of Truth)：接口路径、请求参数、返回结构、文档注释均由 YAML 决定。FastAPI 仅负责实现具体的业务逻辑（Handler）。
3. 运行时动态加载：Python 启动时读取 YAML 注入 FastAPI 的 OpenAPI 规范，并通过装饰器或路由映射自动关联实现函数。

🛠 细化规范与实现标准


1. YAML 接口定义规范 (docs/openapi.yaml)

AI 在生成或修改 YAML 时，必须严格遵守以下结构，且每一层级必须包含详尽的注释 (description)。
• 基本信息：必须包含 info.title、info.version。
• 注释规范：
	• 每个路径（Path）必须有 summary（简短说明）和 description（详细业务逻辑/权限说明）。
	• 每个参数（Parameter）和请求体（RequestBody）的字段必须有 description。
	• 每个状态码（Response 200/400/500）必须定义返回结构，并附带 description。
• 示例要求：每个 Schema 必须包含 example 字段，方便前端 mock。
💡 规范示例 (AI 严格对照此格式生成)：
yaml
openapi: 3.0.3
info:
  title: 用户管理系统 API
  version: 1.0.0
  description: "本文档为系统核心接口定义，由 FastAPI 动态加载。"
paths:
  /api/v1/users:
    get:
      summary: "查询用户列表"
      description: "【权限要求：管理员】根据条件分页查询用户列表，默认返回激活状态的用户。"
      parameters:
        - name: "page"
          in: "query"
          required: false
          schema:
            type: "integer"
            default: 1
          description: "页码，从 1 开始"
      responses:
        '200':
          description: "成功返回用户列表"
          content:
            application/json:
              schema:
                type: "array"
                items:
                  $ref: '#/components/schemas/User'
components:
  schemas:
    User:
      type: "object"
      required:
        - "id"
        - "name"
      properties:
        id:
          type: "integer"
          description: "全局唯一用户 ID"
          example: 10024
        name:
          type: "string"
          description: "用户真实姓名"
          example: "张三"
Use code with caution.

2. FastAPI 动态注册与运行规范 (app/main.py)

AI 在编写 Python 启动代码时，必须实现以下逻辑，严禁写死 app.get 的常规硬编码模式。

A. 契约注入与 Swagger 同步

加载 YAML 并覆盖 FastAPI 默认的 openapi() 方法，确保浏览器访问 /docs 看到的文档与 YAML 完全一致。

B. 显式路由映射机制 (Explicit Route Mapping)

为了保证代码的可维护性与 IDE 的跳转能力（Ctrl+Click），不要使用纯自动化魔法隐式反射（如根据字符串去猜测函数名），应该采用显式路由字典或特定路径装饰器。
💡 规范实现代码 (AI 应当生成的标准脚手架)：
python
import os
import yaml
from fastapi import FastAPI, APIRouter
from fastapi.responses import JSONResponse

# =====================================================================
# 1. 业务逻辑实现层 (Handlers)
# =====================================================================
# 注意：函数签名（入参名、类型）需与 YAML 定义保持逻辑一致

async def handle_get_users(page: int = 1):
    """
    对应 YAML 中的 GET /api/v1/users
    业务逻辑在此处编写，入参由 FastAPI 自动依赖注入和校验
    """
    return [
        {"id": 10024, "name": "张三"},
        {"id": 10025, "name": "李四"}
    ]

# =====================================================================
# 2. 路由映射表 (Route Registry)
# =====================================================================
# 明确将 YAML 中的 [Path][Method] 与 Python 中的实体函数绑定
ROUTE_MAP = {
    "/api/v1/users": {
        "GET": handle_get_users
    }
}

# =====================================================================
# 3. 动态加载与内核启动
# =====================================================================
def create_app(yaml_path: str = "docs/openapi.yaml") -> FastAPI:
    if not os.path.exists(yaml_path):
        raise FileNotFoundError(f"无法找到契约文件: {yaml_path}")

    with open(yaml_path, "r", encoding="utf-8") as f:
        openapi_spec = yaml.safe_load(f)

    # 初始化 FastAPI，接管原生 openapi 路径
    app = FastAPI(openapi_url="/openapi.json")

    # 强行注入手写的 YAML，使 Swagger 界面与契约 100% 同步
    app.openapi = lambda: openapi_spec

    # 根据 YAML 的定义，结合映射表，动态注册路由到 FastAPI 内核
    router = APIRouter()

    paths = openapi_spec.get("paths", {})
    for path, methods in paths.items():
        for method, spec_details in methods.items():
            method_upper = method.upper()

            # 检查是否有对应的 Python 实现
            handler = ROUTE_MAP.get(path, {}).get(method_upper)
            if not handler:
                # 生产安全：如果定义了接口但没写代码，注册一个 501 未实现提示，防止程序崩溃
                async def not_implemented_fallback(*args, **kwargs):
                    return JSONResponse(status_code=501, content={"detail": f"接口 {path} [{method_upper}] 暂未实现"})
                handler = not_implemented_fallback

            # 动态向 FastAPI 实例注册路由
            router.add_api_route(
                path=path,
                endpoint=handler,
                methods=[method_upper],
                summary=spec_details.get("summary"),
                description=spec_details.get("description")
            )

    app.include_router(router)
    return app

app = create_app()
Use code with caution.

🛑 AI 行为红线（边界约束）

• 禁止出现未注释字段：AI 在自动扩充 openapi.yaml 文件的 components 或 paths 时，如果漏掉 description，视为不合格代码。
• 严禁编写重复的 Pydantic 模型：既然使用了动态注册，复杂的请求体校验应尽量通过第三方库（如 openapi-core 运行时校验）或者要求 AI 在 ROUTE_MAP 同级显式绑定 Pydantic 类，严禁在 main.py 里手动重写一遍与 YAML 字段一模一样的 Model 类。
• 鲁棒性要求：YAML 文件读取失败、或 YAML 内语法错误时，Python 程序必须能捕获异常并抛出清晰的错误日志，不能静默失败。
