# 数据库规范


## 1. 统一的数据库/用户/密码创建脚本

每个应用必须提供：

```text
scripts/db_create.sh
```

用于创建：

* 数据库
* 数据库用户
* 数据库密码
* 数据库权限

例如 PostgreSQL：

```text
数据库：
my_service

用户：
my_service

密码：
默认：<请设置独立密码>
```

## 2. 数据库创建必须幂等

脚本应该可以重复执行：

```bash
./scripts/db_create.sh
./scripts/db_create.sh
./scripts/db_create.sh
```

而不会因为：

```text
database already exists
user already exists
```

导致整个部署失败。

例如 PostgreSQL 可以先检查：

```sql
SELECT 1
FROM pg_database
WHERE datname = 'my_service';
```
