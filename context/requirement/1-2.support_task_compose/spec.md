# 阶段二：任务编排与基础执行

## 1. 目标与依赖

基于阶段一接口资产，完成任务编排、固定或 REST 动态全局参数初始化、顺序执行及结果查询。响应提取用于全局参数所引用步骤的初始化响应，验收不依赖实时进度。

## 2. 任务管理与步骤

- 任务属于项目，支持列表、创建、编辑、复制、删除和详情；名称必填且项目内唯一。
- 配置名称、描述、HTTP/HTTPS 运行地址、请求超时、固定或 REST 动态全局参数和有序步骤。地址可含路径前缀，不含 query 或 fragment。
- 超时默认 30 秒，可设为 1～300 秒。草稿可无步骤，运行至少一个步骤。
- 只能选择本项目接口，绑定具体 YAML 版本；页面显示文件、版本、方法及路径。
- 步骤有稳定 ID 和展示序号，支持添加、复制、移除及排序；同一接口可多次添加。
- YAML 更新不自动修改任务；编辑时提示存在新版本，显式重新选择后重新校验参数。

## 3. 全局参数来源与绑定

- 全局参数包含名称、数据类型、取值来源及敏感标记，名称任务内唯一；数据类型支持 string、integer、number、boolean、object、array。
- 取值来源选择“固定（fixed）”或“REST（rest）”，与数据类型分开。固定来源保存保留 JSON 类型的 value；REST 来源保存 rest_source（step_id 与 extract_expression），不保存预览或上次运行值到 value。
- REST 配置弹框选择本任务的具体 task_steps，显示所引用步骤的接口名称，配置响应取值表达式。接口、YAML 版本和请求绑定复用该步骤，不在参数中重复配置。新步骤先保存取得稳定 ID，再设置参数引用；运行地址和超时继承任务配置。复制任务时新建步骤并重新映射参数的 step_id。删除被引用步骤必须同时解除或改绑参数引用。
- 表达式支持点分字段和非负数组下标，例如响应 `{"data":{"a":1}}` 的 `data.a` 提取整数 `1`，`data.items[0].id` 提取数组首项字段。不支持脚本、函数、通配符、运算或字符串模板；缺字段、null、非 JSON 及数据类型不匹配明确失败，不隐式转换类型。
- 点击预览时发送真实 REST 请求，将提取结果自动填入界面预览；敏感值隐藏。预览仅执行所需初始化步骤，不执行后续任务步骤、不创建任务运行、不修改已保存配置，任务运行时仍重新获取。
- 全局参数数组顺序决定初始化顺序。所引用步骤请求绑定支持字面值或该步骤首次执行前已初始化的全局参数，禁止自身、后序、不存在的引用及循环依赖。同一步骤可供多个参数提取同一次响应，本次运行最多请求一次。预览提交所需固定值、前序参数和带稳定 ID 的步骤配置，按顺序初始化至目标参数。
- 接口参数和 JSON 请求体字段可配置字面值或整体引用一个全局参数，保存为结构化绑定，保留类型；不支持字符串内部模板拼接。
- 保存和运行前校验必填、类型、引用存在；可选字段未配置则不发送。接口默认值可首次填入，用户可修改。
- path、query 正确 URL 编码；query 数组以重复键发送，例如 `id=1&id=2`；对象 query 暂不支持，必须明确报错。
- 地址前缀与接口路径正确拼接；JSON 对象和数组按结构序列化。
- 认证 header 可配置字面值或参数引用；header 不得覆盖 HTTP 方法、请求地址等执行配置。

## 4. 运行规则

- 点击运行先校验配置；失败不发送请求。成功后保存运行记录和不可变配置快照。
- 修改任务或 YAML 不影响已创建运行；每次运行独立初始化全部全局参数，动态值仅保存在该运行的参数结果中，不修改配置快照或任务配置。
- 同一任务有未结束运行时拒绝重复启动；不同任务可以独立运行。
- Pipeline 1 按配置顺序初始化全局参数：固定来源读取配置值，REST 来源先执行快照中的引用步骤，再按表达式提取并校验数据类型，持久化每项初始化状态及结果。全部初始化成功并校验步骤实际绑定后，Pipeline 2 按序执行未被参数引用的任务步骤，初始化步骤不重复执行；全部步骤均为初始化步骤时，初始化成功即可运行成功。不并行、不自动重试、不自动跟随重定向。
- 保存及启动的静态校验不调用 REST。初始化 HTTP 状态错误、超时、连接失败、非 JSON、提取失败或类型不匹配时，运行失败；后续参数与所有未执行步骤跳过，已发送初始化请求保留记录。
- 每步发送前先持久化请求记录，发送后保存响应；刷新或关闭页面不终止服务端执行。
- 运行状态：待运行、运行中、成功、失败。步骤状态：待执行、执行中、成功、失败、已跳过。
- HTTP 2xx 成功；其他状态、连接错误及超时失败。失败后后续步骤跳过。
- 服务重启将遗留未完成运行标记为执行中断失败，不自动续跑，避免重复请求。
- 删除任务需确认并删除关联运行记录；运行中的任务禁止删除。

## 5. 记录与页面

- 请求记录区分全局参数初始化和任务步骤阶段，统一关联具体运行步骤；参数初始化结果通过 request_id 关联请求，多参数可共享同一响应；包含运行 ID、参数或步骤 ID、阶段内序号、方法、实际 URL、请求头和体、响应状态码及头和体、开始/结束时间、耗时和错误原因。
- 敏感参数在页面及日志脱敏；Authorization、Cookie、Set-Cookie 头默认脱敏。
- 交付任务列表、编辑及排序、参数来源选择、REST 配置弹框与预览、运行入口、历史列表、含参数初始化状态与结果的运行详情和请求详情。本阶段手动刷新查询即可。

## 6. 验收标准

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| P2-01 | 编排三个接口、排序、保存再打开 | 步骤、版本、参数及配置一致 |
| P2-02 | 参数绑定到 path、query、header、JSON 字段 | 模拟服务收到正确编码和类型，结构未丢失 |
| P2-03 | 缺必填、引用不存在、类型错误 | 明确定位错误，无 HTTP 请求发出 |
| P2-04 | 三步均返回 2xx | 按序各执行一次，运行成功，记录完整 |
| P2-05 | 第二步返回 500、超时或连接失败 | 第二步失败，第三步跳过，原因可区分 |
| P2-06 | 运行中修改任务、更新 YAML、刷新页面 | 原快照继续执行，记录不变 |
| P2-07 | 同任务重复启动，另一个任务同时运行 | 同任务仅一个活动运行，不同任务数据隔离 |
| P2-08 | 执行中重启服务 | 运行标记中断失败，不重复执行 |
| P2-09 | 使用敏感参数并查看详情、日志 | 请求正常发送，敏感值不直接展示 |
| P2-10 | REST 返回 `{"data":{"a":1}}`，配置 `data.a` | 预览得到整数 1；保存 REST 配置而非预览值 |
| P2-11 | REST 值每次调用变化，任务连续运行两次 | 每次先初始化全局参数，步骤使用该次值，历史结果相互隔离 |
| P2-12 | 初始化接口失败、响应非 JSON、字段不存在或类型错误 | 错误分类及参数定位明确，后续参数和任务步骤跳过 |
| P2-13 | REST 参数引用的步骤请求使用前序参数 | 按顺序获取并保留类型；自身、后序及循环依赖在发送请求前拒绝 |
| P2-14 | 两个 REST 参数引用同一步骤，分别提取不同字段 | 初始化步骤只请求一次；后续阶段不重复执行，多参数共享请求记录 |
| P2-15 | 复制任务或删除被引用步骤 | 复制后 step_id 指向新任务步骤；未解除参数引用时拒绝删除步骤 |

提供可记录顺序和参数、返回成功或失败、模拟延迟的 HTTP 服务。验收不依赖真实接口，服务重启后运行历史仍可查询。
